# 🤖 Agente Calificador de Leads (n8n) 

**Autor:** Luciano Albarenque · Curso IA Automation – Avanzado 

Agente que atiende consultas comerciales por chat, califica prospectos con el criterio **BANT** (CALIENTE / TIBIO / FRÍO), los registra en Google Sheets y reporta cada ejecución por Gmail para la supervisión humana.
